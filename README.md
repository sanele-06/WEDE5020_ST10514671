# Sweet Treats Bakery Website - Part 1

## Project Description
Responsive 4-page website for Sweet Treats Bakery using HTML5 and CSS3.

## Pages Included
1. index.html - Home page with welcome message
2. about.html - About us and bakery history  
3. services.html - Services offered by bakery
4. contact.html - Contact details and location

## CSS Features
- External stylesheet: css/style.css
- Responsive design with media queries for mobile
- Bakery theme colors: brown and gold
